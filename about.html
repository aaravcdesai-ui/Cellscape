Privacy

Last updated: November 16, 2026

What the website does

Optional feedback: “Give feedback” opens a separate Google Form in a new tab. The form asks about your experience using Cellscape and does not request your name or email address. Your feedback is sent to the site operator through Google Forms only when you submit it. Please avoid personal information in your comments. Google processes visits and submissions under its privacy policy.

The site has no accounts, contact forms, advertising, analytics, tracking pixels, or embedded social-media widgets. The student quiz does not set cookies or use session storage. Browser local storage is used only to keep your own notebook text, saved structures, and lesson checks on this device (see below). The separate admin dashboard uses an HttpOnly, same-site login cookie that expires after one hour; it gives the site operator access to anonymous quiz records. Signing out revokes that admin session. Admin login attempts are temporarily rate-limited using connection addresses held in server memory for about 15 minutes. Admin credentials are stored as a salted password hash, not plaintext. When the quiz backend is running, starting a quiz creates an anonymous session and sends your chosen answers, hint requests, and answer reveals to that server. The quiz displays whether saving is available. No name or email is requested.

Notebook text, saved-structure bookmarks, and protein-journey lesson checks are kept in this browser’s local storage on this device so they survive a reload. They are never sent to the server. Use “Clear saved work” in the notebook to delete notes and bookmarks, especially on a shared computer; clearing this site’s data in your browser removes all of it. Guided-discovery progress, experiment predictions, and targeted-review priorities stay in the open page and reset on reload. You can download notebook text at any time. Images added to the image workspace are opened locally in browser memory, are never uploaded, and can be removed from the workspace. Snapshots and 3D model exports are generated in your browser. Tissue-pattern previews are original SVG schematics, not microscope photographs. Mixed-practice answers are saved under the same anonymous quiz policy. Selections and displayed scores reset when you reload or close the page. If saving is on, anonymous quiz records remain in the server database: specimen, question IDs, choices, correctness, hint/reveal events, and timestamps. The default retention period is 30 days; expired records are removed at server startup and on quiz submissions. A server operator can also run the purge command. Previously exported copies must be deleted separately by the operator. The current lesson is reflected in the address fragment so you can navigate between views. The site does not ask for camera, microphone, or location access.

Files and hosting

Images, scripts, styles, and the 3D library load from the same host as this page. Image generation happened during development; browsing the site does not send prompts, answers, or images to an AI service. Quiz records go only to the same server serving this notebook. The application does not store IP addresses or user-agent strings in its quiz database. Hosting infrastructure may maintain separate request logs.

Your browser still sends ordinary web requests to the hosting provider. If this site is served through GitHub Pages, GitHub states that it logs visitors' IP addresses for security purposes. Read GitHub Pages information and the GitHub General Privacy Statement. Local previews are served by the local server instead. Hosting logs are separate from the quiz and are governed by the provider's policies.

Links and questions

External reference sites receive a request when you choose to visit them and have their own privacy policies. These pages request that browsers omit referrer information on outgoing links. For questions about this notebook, contact the person who shared it with you; please avoid submitting personal information in the optional feedback form.
